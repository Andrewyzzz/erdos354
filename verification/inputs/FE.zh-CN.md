# Erdős #354：有限前缀缺口的非零位衰减

日期：2026-09-09。

## 0. 状态和本轮结论

这是带完整推导的研究工作稿，尚未独立同行审核，不主张文献首创。
本文没有证明一般 Erdős #354。无限量词由下文证明承担，不由有限计算承担。

本轮得到：

1. 对任意合法的严格交错双列、任意有限前缀，补齐长度后的缺口数满足
   `Q_n <= 2(M+N+10) 2^n (1-1/(32N))^(K_n/2)`。
   这里 K_n 是前 n 个转换中至少一列非零的次数。完全不假定数字随机、正密度或存在零块。
2. 这给出实际有限 X 上的永久缺口上界，而不是先 X 趋于无穷的自然均值估计。
3. 如果比值无理且 `K_n/log(n+2) -> infinity`，则强完全。
4. 假设无理比值参数不完全，在每个足够深的连分数匹配层都有
   `K_n <= 64N log n + O_{alpha,beta}(1)`。
5. 因此，全部无理比值的不完全参数对（若存在）的 Hausdorff 维数为零。
   零维不等于空集，不能当作一般猜想的证明。
6. 结合 Bailey–Borwein–Crandall–Pomerance 的代数数二进位定理，若至少一个参数
   是代数无理数，且两参数比值无理，则完全。另一参数可以是任意正实数。
   这不解决 `(sqrt(2) beta,beta)` 对任意超越 beta 的情形。

整个证明不使用上一份自然密度一结论，也不假设尚未证明的谱分离。

## 1. 合法归约和记号

原参数 alpha_orig,beta_orig 比值无理。仅分别删除有限前缀、必要时交换，可取尾部参数

    1 <= beta < alpha < 2 beta,
    N=floor(beta) < M=floor(alpha) < 2N.

这是向上二进缩放，不使用向下缩放。若证明这对尾部完全，则原序列完全。
本文的有限计数先针对这一对尾部；原序列永久缺口数不超过尾部永久缺口数。

令

    a_i=floor(2^i alpha), b_i=floor(2^i beta), i>=0,
    a_0=M, b_0=N,
    u_i=a_(i+1)-2a_i, v_i=b_(i+1)-2b_i, w_i=u_i+v_i,
    K_n=#{0<=i<n : w_i>0}.

其中 u_i,v_i 属于 {0,1}。严格整数次序在递推中保持：

    b_i<a_i<2b_i, b_i<a_i<b_(i+1),

排序的相邻项至多为前项两倍。因严格次序，N>=2。

定义

    P_n=P(a_i,b_i:0<=i<n), P_0={0},
    S_n=sum_(i<n)(a_i+b_i),
    L_n=a_n+b_n,
    D_n=L_n-S_n=M+N+sum_(i<n)w_i,
    Q_n=L_n-|P_n|,
    e_n=S_n+1-|P_n|=Q_n-D_n+1.

**不要混淆 L_n 与 S_n，也不要混淆 Q_n 与真实前缀缺口 e_n。**
D_n>0，所以 P_n 位于 [0,L_n-1]，Q_n 就是该补齐窗口内的缺口数。

## 2. 一个固定的有限间隙界

若升序正整数权重 c_j 满足 c_(j+1)<=2c_j，则

    c_(j+1)-sum_(i<=j)c_i <= c_j-sum_(i<j)c_i <= c_0.

逐项加入元素，子集和是旧集合与其平移的并。各自内部间隙不增；若两包分离，
新间隙就是上述差额。因此每个有限前缀子集和中，邻接取值的间隙不超过 c_0。

对本题 c_0=N。故 P_n 在 [0,S_n] 内的每个连续缺口段长度至多 N-1。
补齐窗口末端额外的缺口段长度是 D_n-1。

## 3. 周期缺口字串和实际新增表示

把 [0,L_n-1] 的缺口指示函数周期延拓，记为 h_n。对周期为 L 的 0-1 函数 h 定义

    J_t(h)=sum_(x mod L) |h(x+t)-h(x)|.

它满足 J_(-t)=J_t、J_(s+t)<=J_s+J_t，并且 J_1 等于循环缺口段数的两倍。
由于 0,S_n 都属于 P_n，第2节给出

    Q_n <= (N/2)J_1(h_n)+D_n.                         (3.1)

定义实际新增表示数

    G_n=|P_(n+1)|-2|P_n| >=0.

非负性来自两个**不交的**子集 P_n 和 P_n+L_n；因为 S_n<L_n。
其余两个平移是 P_n+a_n 与 P_n+b_n。于是精确地有

    P_(n+1)=P_n+{0,a_n,b_n,L_n},
    Q_(n+1)=2Q_n+w_n-G_n.                             (3.2)

G_n 统计新增的不同整数，不统计掩码数量。

### 3.1 大步平移边界

设 a=a_n,b=b_n,L=a+b。将 P_n 视为模 L 的集合 C。
(C+a)\C 的每个余数至少给出一个 P_(n+1) 中、不在两份 P_n 与 P_n+L 中的新整数。
每个余数的实际和可直接取 x+a (x in P_n)，不会产生无效表示。因此

    J_a(h_n)=2|(C+a)\C| <=2G_n.                      (3.3)

又 a+b=L，所以 J_b=J_a，且 J_(2a)<=2J_a<=4G_n。

### 3.2 前后两层的字串比较

置 u=u_n,v=v_n,w=u+v，a'=2a+u,b'=2b+v，L'=2L+w。
不加入两个单项平移时，新缺口字串是 `h_n h_n 1^w`。
加入这两个平移后恰好填掉 G_n 个缺口。因此，将 h_n 按旧周期 L 延拓，

    sum_(0<=x<L') |h_(n+1)(x)-h_n(x)| <=G_n+w.       (3.4)

末端 w 个位置的比较只贡献至多 w。没有把不同周期直接视为相同周期。

## 4. 每次非零数字事件都控制单位边界

**核心有限引理。** 若 w_n>0，则

    J_1(h_n) <=16G_n+4G_(n+1)+4w_n.                 (4.1)

证明分两种情况，覆盖三种非零位型。

### 4.1 u=1（v 可以为0或1）

在新周期中，平移 a'=2a+1 的非环绕部分是

    0<=x< L'-a'=2b+v.

由 (3.3) 用于新层和 (3.4)，

    sum_(x=0)^(2b+v-1)|h_n(x+2a+1)-h_n(x)|
       <=2G_(n+1)+2G_n+2w.

这段 x 不长于 L，因此取消 2a 的代价至多 J_(2a)(h_n)<=4G_n。
令 tau(x)=|h_n(x+1)-h_n(x)|，在弧

    I={L-2b,...,L-1}, |I|=2b

上得到

    sum_(x in I)tau(x) <=2G_(n+1)+6G_n+2w.           (4.2)

因为 b<a<2b，I 与 I+b 覆盖整个模 L 圆周。
此外

    sum_(x mod L)|tau(x+b)-tau(x)| <=2J_b(h_n)<=4G_n.

所以

    J_1(h_n) <=2 sum_(x in I)tau(x)+4G_n
              <=4G_(n+1)+16G_n+4w.

### 4.2 u=0,v=1

此时 L'=2L+1，a'=2a。新周期平移的环绕部分从 x=2b+1 起。
在其中取恰好 L 个连续点 x=2b+1,...,2b+L；合法性由 b<a 保证。
环绕后的坐标是 x-2b-1，按旧周期看等于 x+2a-1。
再次用 (3.3)、(3.4)，

    J_(2a-1)(h_n)<=2G_(n+1)+2G_n+2.

取消2a的代价至多4G_n，故

    J_1(h_n)<=2G_(n+1)+6G_n+2,

比 (4.1) 更强。引理得证。

这一步同时追踪两个相邻尺度，处理了回缩路径合并；并没有从“回缩路径很多”
直接推断“不同缺口很多”。

## 5. 两步收缩和所有常数

由 (3.1)、(4.1) 及 w_n<=2，

    Q_n<=8NG_n+2NG_(n+1)+4N+D_n,

因此

    G_n+G_(n+1)>=(Q_n-D_n-4N)/(8N).

把 (3.2) 连用两次：

    Q_(n+2)=4Q_n+2w_n+w_(n+1)-2G_n-G_(n+1).

得到每个非零事件上的收缩

    Q_(n+2) <= (4-1/(8N))Q_n +D_n/(8N)+13/2.         (5.1)

若 w_n=0，则单步有 Q_(n+1)<=2Q_n。

令

    rho=1-1/(32N), z_n=Q_n/2^n.

由 D_n<=M+N+2n<3N+2n，(5.1) 蕴含

    z_(n+2)<=rho z_n+2(n+1)2^(-n),  当w_n>0;          (5.2)
    z_(n+1)<=z_n,                 当w_n=0.             (5.3)

### 5.1 不重叠事件块，避免重复使用同一收缩

从0到n-1贪心分块：零事件占一层；非零事件若有下一层就占两层；
末尾若只剩一个非零事件，单独处理。令 r 为两层事件块个数。
每个事件块至多消费两个非零事件，所以

    r>=(K_n-1)/2, r<=n/2.

若一个事件块起于 i，它至多是第 i+1 块。迭代 (5.2)、(5.3) 后，

    z_n <=rho^r [z_0+(2/rho)sum_(i>=0)(i+1)(2rho)^(-i)] +2^(1-n).

最后项只为可能存在的末尾单独事件预留。
N>=2保证 rho>=63/64，故

    (2/rho)/(1-1/(2rho))^2 <=8064/961<9.

并且 `2^(1-n)<=2rho^r`。又 z_0=M+N-1，因此

    z_n <=(M+N+10)rho^r
        <=2(M+N+10)rho^(K_n/2).

**有限尺度主定理**：对全部 n>=0，

    Q_n <=C_0 2^n rho^(K_n/2)
        <=C_0 2^n exp(-K_n/(64N)),
    C_0=2(M+N+10).                                   (5.4)

这是有限整数前缀上的定理。没有使用 X 趋于无穷的平均范数。

## 6. 转成实际有限 X 上的永久缺口界

记当前尾部的全子集和为 S，H(X)=|[0,X]\S|，X为非负整数。
对于足够大的X，取

    n(X)=ceil(log_2((X+1)/beta)).

则 b_(n(X))>=X+1，所以所有不超过X的表示只需要前n(X)层，

    H(X)<=e_(n(X))<=Q_(n(X)).

又 2^n<=2(X+1)/beta，故

    H(X)<= [2C_0/beta](X+1)exp(-K_(n(X))/(64N)).       (6.1)

加入此前删除的有限头部只会增加可表示数，因此同一上界也控制原始永久缺口。

如果 K_n/log(n+2)->infinity（本文没有下标的log均为自然对数），则对每个固定B>0，

    H(X)=o(X/(log X)^B).                              (6.2)

特别地满足此前的 X/log X 目标。但为使本文结论独立可审核，第7节直接重述所需传播。

## 7. 无理性在哪里进入：匹配尺度上的点态传播

### 7.1 有理网格传播引理

设 theta=alpha/beta，存在互素 p,q、q>=2，满足

    |theta-p/q|<1/q^2.

令 lambda=2^n beta，k=ceil(log_2(8q))，K=2^k。
若 P_n 含宽度 W 的整数区间，且

    W>=3lambda/q+2k,                                 (7.1)

则整个尾部完全。

证明：后面每列k项的子集和，以0<=x,y<K编码，真实和相对
`lambda(theta x+y)`的误差落在[-2k,0]。
q个相位j theta与均匀q点网格逐点循环距离小于1/q，故最大循环空隙不超过3/q。
令 t0=ceil((q-1)theta)。对每个0<=ell<=K-q，使用x=ell,...,ell+q-1，在

    [ell theta+t0, ell theta+K-1]

中提供间隙不超过3/q的点列。两个端点取x=ell即得到；所需y均在[0,K-1]内。
这些窗口重叠，总并为

    J=[t0,theta(K-q)+K-1].

其宽度D满足 `D>=2K-3q+1>K`。用真实和替代理想点后，排序的顺序统计量
各自移动至多2k，故间隙不超过3lambda/q+2k、跨度至少lambda D-2k。
以这些真实和分别平移旧区间，由 (7.1) 拼成宽度至少lambda D的整数区间，
严格超过下一个未用元素floor(lambda K)。以后按真实严格交错序逐项拼接即得完全性。
所有新元素的索引在n之后，与旧表示不交。证毕。

### 7.2 超对数非零位计数足以完全

取theta的收敛分数p_j/q_j，置

    n_j=floor(log_2(q_j/beta)),
    k_j=ceil(log_2(8q_j)).

只考虑n_j足够大。有 `2^n_j beta<=q_j<2^(n_j+1) beta`。
若P_(n_j)有宽度至少 `2k_j+3` 的整数区间，7.1即推出完全性。

反设不完全，则每个连续可表示段至多有 `2k_j+3` 个整数。
e_(n_j)个缺口至多分成e_(n_j)+1段，因此

    e_(n_j)>=(S_(n_j)+2)/(2k_j+4)-1.                  (7.2)

由 `S_n=(alpha+beta)2^n+O(n)`、`k_j=n_j+O_beta(1)`，右边至少
`c_(alpha,beta) 2^(n_j)/n_j`（所有足够大的j）。

结合 `e_n<=Q_n` 和 (5.4)，得到反例必要条件

    K_(n_j)<=64N log n_j+O_(alpha,beta)(1).             (7.3)

所以 K_n/log(n+2)->infinity 时不可能不完全。

**强完全性。** 任意有限删除后，仍可选更深的两个尾部并重新归约。
两个列分别有限移位后，联合非零位数至少为原联合位数的一半减去常数，
故超对数增长保留。将上述定理应用于新尾部，得到强完全。

重要：无理比值不自动蕴含超对数位计数。一般猜想尚未完成。
(7.3)只要求在收敛分母匹配的无穷多个层数稀疏，不能说反例在每一层都稀疏。

## 8. 所有可能的无理比值反例构成Hausdorff零维集合

固定整数矩形 M<=alpha<M+1、N<=beta<N+1，N<M<2N。
由 (7.3)，每个不完全的无理比值参数对，在无穷多个n上满足

    K_n<=C log n,

可取某个只依赖矩形的充分大C；也可直接对所有整数C取可数并。
长度n的两列二进数字共有四种位型00,10,01,11。至多C log n个非零位置的前缀数至多

    sum_(j<=floor(C log n)) binom(n,j)3^j
        =exp(O_C((log n)^2)).

每个前缀对应一个边长2^-n、直径sqrt(2)2^-n的半开参数方格。
对任意d>0，

    sum_n exp(O_C((log n)^2)) (sqrt(2)2^-n)^d <infinity.

取尾部覆盖即可得到这个limsup集合的Hausdorff d测度为0。d任意，故Hausdorff维数为0。
对所有整数矩形、有限移位以及交换操作取可数并，结论仍成立；
逆向二进线性变换是双Lipschitz映射，不改变维数。

因此

    dim_H { (alpha,beta)>0 : alpha/beta irrational,
                            A_(alpha,beta) not complete } =0

（空集按通常约定维数为0）。

这里只陈述无理比值例外集。包含有理比值的不完全参数集可能含曲线，
不能把它一起说成零维。

零Hausdorff维数不等于空集，也不意味着只有有限或可数个例外。
本结论是参数集合的度量信息，不是此前“目标整数的可表示密度一”的重述。

## 9. 至少一个参数为代数无理数的推论

引用的外部输入：Bailey、Borwein、Crandall、Pomerance，
《On the binary expansions of algebraic numbers》，Journal de Théorie des Nombres de Bordeaux
16 (2004), 487–518，Theorem 7.1（印刷页501）。

该定理给出：对实代数无理数gamma，次数D>1，存在c_gamma>0使充分大的n满足

    J_gamma(n)>=c_gamma n^(1/D),

其中J统计二进展开至第n位的1的个数。包含整数位与否只差一个固定常数。
这不是关于正规性的猜测，不要求正数字密度。

原文：https://www.numdam.org/article/JTNB_2004__16_3_487_0.pdf

如果alpha/beta无理，并且至少一个参数为代数无理数，则其相应单列1计数就超对数，
联合K_n当然超对数。合法二进移位保持代数性，故第7节适用，得到强完全。
另一参数不必代数。

这包含所有正代数beta的(sqrt(2) beta,beta)，但不包含任意超越beta的这条射线。
“比值为代数无理数”与“至少一个参数为代数无理数”是不同条件。

## 10. 精确验证的对象和未完成事项

运行：

    python erdos354_finite_event_decay.py

程序只使用Python标准库。所有通过/失败判断使用整数或Fraction。
主要检验包括：

- 合法有限前缀的边界不等式、缺口恒等式、两步收缩；
- 任意有限循环0-1集合（不局限于来自地板列）的核心事件边界引理；
- 最坏事件时序下的标量收缩迭代；
- 将总上界平方后消去半整数指数，检验

    Q_n^2(32N)^(K_n) <= C0^2 4^n(32N-1)^(K_n)；

- 全零、单侧变化、双侧变化、混合和伪随机的较长合法前缀；
- 三个固定sqrt(2)比值的独立完整整数区间证书。

统计以同目录results.json的实际运行输出为准。
有限验证不证明无限参数条件、Hausdorff维数或代数数推论；相应全称证明已在正文给出。

本轮没有得出一般K_n/log n趋于无穷，且这本来就不是任意无理数都成立的性质。
例子如非零位位置按约(3/2)^j增长，会有K_n=Theta(log n)，既不满足本轮超对数充分条件，
也不能直接套用此前要求相邻事件位置比最终大于2的两零块定理。
这个观察不是原问题反例，只说明现有两项条件不能未经证明地拼成穷尽二分。

下一主攻点是(7.3)允许的稀疏匹配层：不再需要假定所有稠密、不规则数字也可能制造反例，
但仍必须排除剩余零维参数集中的任何一个真正无理比值反例。
